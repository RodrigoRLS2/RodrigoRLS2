Selected projects
Supervised Agent Orchestrator — AI agents · Python · SQLite · Telegram
An experimental, human-supervised software-task orchestrator. A Claude Code CLI executor works in an isolated Git worktree; an independent Codex CLI reviewer checks deliveries, while human approval remains mandatory. Features include a task state machine, event-based persistence, verification gates, process isolation boundaries, and a credential-free simulated demo.

What it demonstrates: agent architecture, independent review, deterministic state transitions, security boundaries, and testable orchestration.
ENEM API IA — AI data pipeline · n8n · PostgreSQL · Next.js
An open-source fork of an existing ENEM exam API, enriched with AI-generated explanations and subject classifications. Its offline pipeline combines multiple model providers, structured validation against official answer keys, checkpoints, and cost-aware escalation; the public API serves precomputed content without calling an LLM per request.

Measured delivery: 350 enriched questions across the 2022 and 2023 exams, with source attribution and documented validation limits.
Twitch & Kick Highlights — Case Study — n8n · Whisper · Claude · Ollama
A private production-workflow tool for discovering, reviewing, editing, and prioritising livestream clips. Its V2 uses audio analysis, transcription, optional LLM recommendations, n8n event-driven automation, and human-in-the-loop curation.

Measured experiment: an initial blind review of 22 clips compared the original order, audio-only signals, Claude, and a local Ollama model. Results and limitations are documented; a productivity improvement has not yet been established. Source code and internal selection rules remain private.
Shadowing — Product & Technical Case Study — Tech leadership · FastAPI · EdTech

Recognition: PIPA award at IME-USP, supporting the project's continued development.
